# Microsoft WebView2 與 SmartScreen 告知

本軟體包含 Microsoft Edge WebView2 Runtime（Fixed Version）與 Microsoft Defender SmartScreen。

Microsoft Defender SmartScreen 會收集使用者資訊並傳送至 Microsoft。資料處理說明見 [Microsoft 隱私權聲明](https://aka.ms/privacy) 與 [Microsoft Edge 隱私白皮書的 SmartScreen 說明](https://learn.microsoft.com/en-us/microsoft-edge/privacy-whitepaper#smartscreen)。

完整 Microsoft Fixed Runtime 授權條款隨附於 `Microsoft-WebView2-Fixed-LICENSE.en-US.html`。Runtime 內的 Microsoft 與第三方權利告知一併保留。

此告知對應隨附授權的第 4(b) 與第 8 節；本專案保留 SmartScreen。閱讀本頁或工程驗證標記，不會代替使用者對適用條款的同意。
